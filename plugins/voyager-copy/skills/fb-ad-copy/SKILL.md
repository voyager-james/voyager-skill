# Facebook Ad Copy

Interview first, then write. Never draft before the summary is confirmed.

## Workflow

1. **Collect context.** Follow protocol section 1. Pull the offer, audience, proof and brand voice from what is already in the conversation or project.
2. **Round 1.** Ask the questions in `references/interview.md`, skipping any already answered.
3. **Round 2.** Ask only the follow-ups the Round 1 answers trigger.
4. **Readiness gate and summary.** Check the required fields, then post the confirmation summary and wait for a yes.
5. **Route the answers** using the table below, then write.
6. **Quality gate.** Meta compliance checklist, final review checklist, then the human-voice lint.
7. **Deliver** the package, then assumptions, QA notes and next-step offers.

## How answers change the copy

| Answer | What it changes |
|---|---|
| Goal: leads | Name the lead magnet in the body. CTA frames a small, free step. Button: Download or Sign Up. |
| Goal: sales | Body handles price and the main objection. Include guarantee only if the user gave one. Button: Shop Now, Get Offer or Order Now. |
| Goal: webinar or event registrations | Say what they will learn and one qualifier for who it is for. Real date lives in the body, not the headline. Button: Sign Up. |
| Goal: book a call | Frame the call as a fit check with a clear outcome. Include a qualifier so the wrong-fit prospect opts out. Button: Book Now or Apply Now. |
| Goal: awareness | One idea to remember. Softer CTA. Button: Learn More or Watch More. |
| Goal: traffic | Curiosity plus relevance, a clear reason to click. Button: Learn More. |
| Temperature: cold | Lead with problem diagnosis, no product pitch in the hook, low-friction CTA, no urgency. |
| Temperature: warm | Differentiate, add proof, explain the approach briefly. Do not re-explain the problem. |
| Temperature: retargeting | Handle objections, use proof, make the CTA direct. Do not re-sell the problem. Reference what they already saw. |
| Ad type: video | Build the hook batch first (`references/hooks.md`), then write the body for the chosen hook. |
| Ad type: static or carousel | Write the hook directly. Carousel: add a one-line headline per card slot if asked. |
| Tone framework chosen | Use that framework's Hook, Body, CTA structure and its description pattern. |
| Tone: you decide | Use the default 6-beat template. |
| Special Ad Category yes or unsure | Put a flag at the top of the deliverable and avoid eligibility language tied to age or life stage. |
| Income or health claims involved | Use directional outcome language only. See `references/meta-compliance.md`. |

## Deliverable format

```
# Facebook Ad Package: <offer or angle>

Goal: <goal> | Audience: <temperature and who> | Format: <static/video/carousel> | Framework: <name or 6-beat>

## Primary text
<text with the CTA repeated 2 to 3 times>

## Headlines
1. ...
2. ...
3. ...
4. ...
5. ...

## Description
<20 to 30 words>

## CTA button
<button label>

## Hook batch (video only)
<per references/hooks.md>
```

If the user wants more than one package, rotate the tone framework and the opening device between packages, and use the direct-address callout ("Business owner under $1M:") in only one package per set.

## Final review checklist

- [ ] Exactly 1 primary text, 5 headlines, 1 description, 1 CTA
- [ ] Primary text follows the 6 beats in order, or the chosen framework's arc
- [ ] Hook speaks to the audience's pain, problem, desire, outcome or solution, in their words
- [ ] The first 125 characters work on their own
- [ ] Every headline passes the headline checklist
- [ ] Description is offer-specific and not a repeat of the hook
- [ ] CTA matches the goal and temperature, repeats 2 to 3 times, no pressure language
- [ ] One audience qualifier is embedded in the body
- [ ] Meta compliance checklist passed
- [ ] Human-voice lint exit code 0
