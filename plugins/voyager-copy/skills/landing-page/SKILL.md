# Landing Page Copy

Interview first, then write. Never draft before the summary is confirmed.

## Files to load

| When | File |
|---|---|
| Always, first | `../copy-foundations/references/interview-protocol.md` |
| Always | `../copy-foundations/references/copy-principles.md` |
| Always | `references/interview.md` (the question flow and required fields) |
| Before writing | `references/page-blueprints.md` |
| Before delivery | `../copy-foundations/SKILL.md` (quality gate) |

## Workflow

1. **Collect context.** Follow protocol section 1. Pull the offer, audience, proof and voice from what is already known.
2. **Round 1.** Ask the questions in `references/interview.md`, skipping any already answered.
3. **Round 2.** Ask only the follow-ups the Round 1 answers trigger.
4. **Readiness gate and summary.** Check the required fields, post the confirmation summary and wait for a yes.
5. **Route the answers** using the table below, then write from the matching blueprint.
6. **Quality gate.** Page checklist, then the human-voice lint.
7. **Deliver** the section-by-section copy, then the form spec, build notes, assumptions and next-step offers.

## How answers change the page

| Answer | What it changes |
|---|---|
| Page type | Picks the blueprint in `references/page-blueprints.md`. |
| Traffic: FB cold | Longer, more diagnosis, problem recognition first, low-friction form. Message must match the ad that sent them. |
| Traffic: FB retargeting | Shorter, proof and objections first, direct CTA. |
| Traffic: email | Warm. Skip the introductions, reference the relationship, shorter page. |
| Traffic: organic | Treat as cold to warm, explain who you are and why to trust you. |
| Price given | Show it where the blueprint says to, with the value stack and guarantee if provided. |
| Conversion action | Becomes the one CTA, same words and destination every time. |
| Platform: GoHighLevel | Add the GHL build notes from the blueprint file. |
| Proof provided | Placed in the proof section and repeated near the CTA as a short trust line. |
| No proof provided | Do not invent any. Write the proof section as a labelled placeholder and list what to collect. |
| Objections provided | Each becomes an FAQ or a body line that answers it. |
| Long or short form | Sets the form field count using the friction ladder. |

## Deliverable format

```
# Landing Page Copy: <offer> (<page type>)

Traffic: <source and temperature> | Conversion action: <action> | Platform: <platform>

## Above the fold
Headline:
Subheadline:
CTA button:
Trust line:

## <Section name>
<copy>

... (per blueprint)

## Form
Fields: <list>
Under-form text:

## Build notes
<layout and platform notes>
```

Give 3 headline options for the above-the-fold and recommend one.

## Final review checklist

- [ ] One page, one goal, one CTA (same words and destination each time, repeated 2 to 4 times)
- [ ] No navigation, no competing links
- [ ] Headline is outcome-driven and specific
- [ ] Passes the 5-second clarity test: what is this, who is it for, what do I do
- [ ] Matches the ad or email that sends the traffic
- [ ] Length fits the traffic temperature
- [ ] Proof is real or clearly marked as a placeholder
- [ ] Form fields follow the friction ladder
- [ ] Objections are answered
- [ ] Human-voice lint exit code 0
